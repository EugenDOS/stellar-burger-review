## О проекте

Stellar Burger — это интерактивное веб-приложение для заказа космических бургеров. Проект разработан в рамках обучения на курсе по фронтенд-разработке.

## Стек технологий

- **React** — библиотека для построения пользовательских интерфейсов
- **Redux Toolkit** — управление состоянием приложения
- **TypeScript** — типизация для повышения надежности кода
- **React Router** — маршрутизация и навигация
- **Авторизация пользователей** — регистрация, вход, восстановление пароля
- **Cookies** — безопасное хранение токенов авторизации
- **Защищенные маршруты** — контроль доступа к страницам
- **Тестирование** — модульные тесты редьюсеров
- **Cypress** — функциональное тестирование интерфейса

## Функциональность

- Конструктор бургеров с перетаскиванием ингредиентов (Drag and Drop)
- Лента заказов в реальном времени через WebSocket
- Личный кабинет с историей заказов
- Модальные окна с детальной информацией

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка проекта
npm run build

# Запуск тестов
npm test

# Запуск Cypress тестов
npm run cypress
```
